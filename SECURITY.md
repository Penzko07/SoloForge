# Security

SoloForge is a local offline singleplayer tool. Security issues still matter because the app may eventually inspect game files, save files, and running processes.

## Report

Open a GitHub issue with a minimal reproduction and mark it as security-related in the title.

Do not post exploit code against third-party games, anti-cheat systems, launchers, or online services.

## Scope

In scope:

- unsafe file writes
- save corruption caused by SoloForge
- accidental execution of untrusted imported content
- attribution or license mistakes that cause redistribution risk
- policy bypasses that would enable multiplayer use

Out of scope:

- bypasses for third-party anti-cheat systems
- bypasses for DRM or access control
- vulnerabilities in game clients not caused by SoloForge
